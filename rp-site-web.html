Contexte

Cours de formation
2025–2026
Créer un site web dynamique côté serveur

Dans le cadre du BTS SIO SLAM, il a été demandé de concevoir et développer un site web dynamique intégrant des pages générées côté serveur en PHP, avec une base de données MySQL. Le projet visait à mettre en pratique les compétences de développement web (C3, C4, C5) en conditions réelles de projet.

Environnement technique

HTML5 CSS3 PHP 8 MySQL Apache (XAMPP/WAMP) phpMyAdmin Git VS Code

Missions réalisées

01

Conception de la structure du site

Définition de l'arborescence des pages, création du wireframe et du cahier des charges simplifié. Choix de l'architecture MVC simplifiée en PHP.

C4
02

Développement front-end

Intégration HTML5/CSS3 responsive avec navigation, formulaire de contact et pages de contenu dynamique. Utilisation de Flexbox/Grid CSS.

C3
03

Développement back-end PHP

Connexion à MySQL via PDO, requêtes préparées, gestion des sessions utilisateurs, CRUD sur les données du site (articles, catégories). Sécurisation contre les injections SQL.

C5
04

Mise en ligne & tests

Déploiement sur serveur local (XAMPP) puis sur hébergement. Tests fonctionnels, validation W3C, vérification de la compatibilité navigateur.

C3 C5
