📖 Contexte — L'histoire de la réalisation

Dans le cadre de la formation BTS SIO SLAM, j'ai réalisé un site web dynamique complet en utilisant les technologies HTML, CSS et PHP. L'objectif était de créer un site fonctionnel intégrant une base de données, des formulaires avec traitement côté serveur, et une interface utilisateur responsive.

Ce projet m'a permis de mettre en pratique les compétences acquises en cours tout en respectant les normes du W3C, les procédures de versioning et les bonnes pratiques de développement web.

🖥️ Environnement technologique

HTML5 CSS3 PHP 8 MySQL Apache / WAMP VS Code Git Validateur W3C

✅ Ce qui a été réalisé

  • Conception et maquettage des pages (arborescence, wireframe)
  • Développement du front-end : HTML5 sémantique, CSS3 responsive
  • Développement du back-end : scripts PHP de traitement des formulaires
  • Création et connexion à une base de données MySQL
  • Validation du code HTML/CSS avec le validateur W3C
  • Gestion des versions du projet (documents techniques)
  • Déploiement et livraison des livrables validés
