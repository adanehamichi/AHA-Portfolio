Thématique : SGBD

Les Systèmes de Gestion de Bases de Données sont au cœur de toute application métier. Leur évolution impacte directement l'architecture logicielle, la performance, la sécurité et le coût des projets informatiques.

Nov. 2025 SQL vs NoSQL

PostgreSQL 17 : la révolution des index et du partitionnement

La version 17 de PostgreSQL apporte des améliorations majeures sur le partitionnement, les index et les performances de requêtes parallélisées. Le partitionnement déclaratif devient plus flexible et performant.

Déc. 2025 Cloud

Le marché des SGBD cloud dépasse 80 Mds$ en 2025

Le marché mondial des bases de données cloud atteint un record historique porté par AWS, Azure et GCP. Les SGBD managés (RDS, Cosmos DB, Cloud SQL) dominent le paysage enterprise.

Source Gartner →
Jan. 2026 NoSQL

MongoDB 8 : la base documentaire accélère les transactions ACID

MongoDB 8 renforce la prise en charge native des transactions ACID multi-documents, rapprochant les bases NoSQL du niveau de fiabilité traditionnellement réservé aux SGBDR.

Source MongoDB →
Fév. 2026 Sécurité

Chiffrement en transit et au repos : les nouvelles normes SGBD

Les réglementations RGPD et NIS2 imposent un chiffrement systématique des données au repos et en transit. SQL Server, PostgreSQL et Oracle renforcent leur TDE et TLS par défaut.

Source CNIL →
Mars 2026 IA

L'IA vectorielle transforme les SGBD : pgvector, Atlas Vector Search

L'intégration d'index vectoriels dans les SGBD (pgvector pour PostgreSQL, Atlas Vector Search pour MongoDB) ouvre la voie à des requêtes sémantiques directement en base, sans pipeline externe.

Source pgvector →
Avr. 2026 Écosystème

SQL Server 2025 : l'intégration native d'Azure et du Machine Learning

Microsoft SQL Server 2025 intègre des capacités de scoring ML directement en T-SQL, rapprochant l'analyse prédictive de la couche données. Pertinent pour les environnements .NET/ASP.NET Core.
